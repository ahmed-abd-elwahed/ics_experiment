141 set A questions, one frozen search query per question, retrieval only, one judge (Claude Haiku 5.5). Strict truth coverage decides: a document gives a value for patients like this one and the true value lies in its range or within about 15%. Δ is paired against the baseline over the same questions, with 95% bootstrap intervals (green: excludes zero).
