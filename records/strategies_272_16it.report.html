What was run

  • 272 cases from cases/combined_272_whole_chunking.json, each run with every strategy: 1088 case runs.
  • Each strategy could ask at most 16 questions and could stop earlier by its own rule. When it stopped, it gave a differential of up to 10 diagnoses with probabilities.
  • Strategy model: anthropic/claude-haiku-5.5. Simulated environment model: openai/gpt-6-luna; literature sources europe_pmc, litsense.
  • Coding: ICD-11 MMS 2024-01, first result of the flexible search for the diagnosis name. A prediction counts as a hit only when its code equals the true diagnosis code exactly.
  • Total time 3.1 h; total cost $25.70 (strategies $12.48, environment $13.22).

Reading these numbers

  • Exact code match is strict: a correct diagnosis worded so that the search returns a neighbouring code (a parent, a sibling, or a code with a different extension) counts as a miss.
  • One run per case and strategy. LLM sampling differs between runs, so small differences between strategies may not repeat.
  • The stopping thresholds are starting values and were not tuned.
  • Answers marked "literature" are synthesized by the simulated environment when the case text is silent; they are plausible, not facts about the patient.
